FastAPI · Watch Integration

모델 실험 코드를 건드리지 않고
워치 CSV를 받을 수 있게 분리했습니다

FastAPI 코드는 실제 제품 서버로 확정된 구성이 아니라 Galaxy Watch 데이터와 모델을 연결해 검증하기 위한 독립 테스트 서버입니다.

01

분리한 이유

실험 보존

노트북·학습 스크립트와 서비스 코드를 분리해 기존 결과를 덮어쓰지 않습니다.

입력 통일

Android가 생성한 CSV 하나를 calibration과 prediction 양쪽에서 사용합니다.

모델 교체

부정맥과 스트레스 endpoint가 같은 전처리·baseline을 공유할 수 있습니다.

실패 명시

품질 부족 시 억지 예측 대신 unavailable을 반환합니다.

02

API 계약

MethodEndpoint역할
GET/health서버 상태 확인
GET/api/v1/model/info모델 버전·threshold 확인
POST/api/v1/calibrations정상 5분 CSV에서 baseline 생성
POST/api/v1/predictions부정맥 가능성 분석
POST/api/v1/stress/predictions급성 스트레스 실험 분석
 
Content-Type: multipart/form-data
Authorization: Bearer {token}

fields:
  subject_id
  baseline_id
  file
03

서버 내부 처리 흐름

CSV 검증 — Timestamp, HR, PPG_GREEN 필수 열과 업로드 크기를 확인합니다.
60초 전처리 — PPG peak, RR, 13개 HR·HRV 피처와 품질 상태를 계산합니다.
baseline 조회 — subject_id와 baseline_id가 연결된 정상 profile을 읽습니다.
26개 피처 변환 — 상대 변화와 z-score를 모델 입력으로 만듭니다.
윈도우 예측 — 각 유효 60초 구간의 확률을 계산합니다.
최종 응답 — 현재는 가장 높은 이상 확률을 대표값으로 반환합니다.
04

로컬 검증 환경

항목설정
실행 명령python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
접속 주소http://{PC의 LAN IPv4}:8000
기본 개발 tokenlocal-dev-token
최대 업로드5MB
baseline 저장서버 런타임 JSON 저장소
최소 입력 길이유효 신호 55초 이상
워치에서 localhost는 워치 자신을 의미하므로 사용할 수 없습니다. PC와 워치를 같은 Wi-Fi에 연결하고 PC의 IPv4를 사용했습니다.
05

현재 서버의 경계

프로토타입 인증

고정 개발 token은 외부 공개 환경에 적합하지 않습니다.

단일 서버 저장

baseline 지속성과 다중 인스턴스 동기화가 보장되지 않습니다.

최댓값 집계

여러 윈도우 중 최댓값은 민감하지만 한 번의 노이즈에도 영향을 받습니다.

제품 분리

실제 운영 채택 전에는 보안, 저장소, 모니터링과 모델 검증이 별도로 필요합니다.
