실사용 성능은 같은 의미가 아닙니다

공공 ECG 안에서의 그룹 교차검증, 다른 출처의 1~5번 데이터, Galaxy Watch PPG 검증은 서로 다른 수준의 증거입니다. 결과를 섞지 않고 무엇을 확인했는지 구분했습니다.

03

Galaxy Watch 정상 외부 검증

Calibration

약 304초, 7,600행, 25Hz 데이터에서 5개 유효 구간을 만들었습니다.

Evaluation

약 312초, 7,800행에서 5개 유효 구간과 0개 실패 구간을 얻었습니다.

부정맥 결과

다섯 구간 모두 normal, 최고 이상 확률은 약 26.9%였습니다.

스트레스 결과

동일 정상 데이터에서 약 65.0%가 나와 실제 오탐 위험을 확인했습니다.

확인된 부분 — Watch CSV에서 PPG peak와 RR·HRV를 계산하고 개인 기준 모델까지 연결하는 end-to-end 흐름은 정상 작동했습니다.
04

정상 오탐을 더 위험하게 본 이유

사용자가 정상인데 반복적으로 부정맥 경고를 받으면 불안과 경보 피로가 커지고 결국 기능을 신뢰하지 않게 됩니다. 그래서 recall만 올리는 것보다 정상 specificity와 false positive rate를 별도로 관리해야 합니다.

임계값 조정 — validation OOF에서 허용 가능한 정상 오탐률을 먼저 정합니다.
반복 확인 — 한 구간 최댓값만으로 경고하지 않고 연속·다수 구간 조건을 검토합니다.
품질 게이트 — 움직임, off-body, peak 불일치가 있으면 예측 대신 unavailable로 처리합니다.
메시지 제한 — 진단 표현 대신 재측정과 추가 확인이 필요한 가능성으로 안내합니다.
05

아직 확보하지 못한 증거

실제 양성 Watch 데이터

Galaxy Watch로 측정한 의학적으로 확인된 부정맥 구간이 없습니다.

대규모 정상 대상자

다양한 연령·성별·피부·활동 조건의 정상 오탐률을 측정하지 못했습니다.

동시 ECG 기준

Watch PPG와 임상 ECG를 동시에 측정한 정답 비교가 없습니다.

장기 변화

baseline 노후화, 일간 변동과 장기 사용 중 재보정 주기를 검증하지 못했습니다.

따라서 — 현재 결과는 기술 프로토타입의 가능성을 보여주지만 의료기기 성능이나 임상 진단 정확도로 주장할 수 없습니다.
