01

출발점 — 작은 데이터로 4개 상태를 구분할 수 있을까

초기 목표는 약 60초의 생체신호에서 정상, 부정맥, 급성 스트레스, 피로·과로를 구분하는 단순한 AI 분류기를 만드는 것이었습니다.

처음 가진 데이터

1번부터 5번까지 직접 만든 측정 데이터가 있었지만 대상자와 라벨 수가 적고, 상태별 측정 조건도 충분히 통제되지 않았습니다.

첫 번째 판단

직접 측정 데이터만으로 학습하지 않고 PhysioNet과 공개 웨어러블 데이터로 정상·상태별 기준을 먼저 구성하기로 했습니다.

공통 표현

ECG와 PPG 원본 형태는 다르지만 beat 간격인 RR을 중심으로 HR·HRV 피처를 계산하면 하나의 표 형식으로 비교할 수 있다고 판단했습니다.

초기 원칙

복잡한 딥러닝보다 Random Forest와 부스팅 모델을 사용하고, 전처리·CSV 생성·기본 평가가 재현되는 것을 우선했습니다.

02

의사결정 여정 — 문제를 확인할 때마다 구조가 바뀌었습니다

각 단계에서 발견한 문제와 실제로 내린 결정을 시간 순서로 정리했습니다.

단계 확인한 문제 실행한 실험 결정
01 · 데이터 확보 직접 측정 데이터의 양과 라벨 신뢰도가 부족함 MIT-BIH Normal, MIT-BIH Arrhythmia, WESAD, Stress-Predict, MEFAR 검토 공공데이터 중심의 상태별 학습 데이터 구축
02 · 전처리 통일 ECG, BVP, IBI가 서로 다른 형식 60초 윈도우에서 peak → RR → HRV 공통 피처 생성 13개 핵심 HRV 피처를 공통 표현으로 사용
03 · 4분류 정상과 피로가 많이 혼동되고 상태별 데이터 수도 다름 4분류 혼동행렬, 2단 분류와 개별 이진 모델 검토 상태마다 정상과 비교하는 독립 이진 모델로 전환
04 · 모델 비교 모델을 복잡하게 하면 실제 이득이 있는지 불분명 Random Forest, XGBoost, LightGBM, CatBoost 그룹 5-fold 비교 성능과 단순성이 균형 잡힌 Random Forest 우선
05 · 부정맥 실험 정상 데이터 수와 출처 구성을 어떻게 잡을지 고민 정상 3,000개와 부정맥 508개, 대상자 그룹 61개로 평가 부정맥 F1 약 90%의 Random Forest 선택
06 · 실측 검증 공공데이터 성능은 높지만 1~5번 실측이 대부분 부정맥으로 나옴 실측 HR·HRV와 공공 정상 profile 차이 비교 절대값만으로는 개인차를 처리하기 어렵다고 판단
07 · 개인화 사용자마다 평소 HR·HRV가 다름 출처별 정상 profile 대비 relative·z-score 모델 비교 5분 개인 Calibration을 실제 추론 기준으로 적용
08 · 실제 연동 노트북 결과를 Watch 입력에 적용할 실행 경로가 없음 FastAPI Calibration·Prediction API와 실제 25Hz PPG 검증 Watch → 서버 → 모델 → 결과 표시 흐름 완성
09 · 상태 확장 변화율이 스트레스·피로에도 효과적인지 불명확 급성 스트레스와 피로의 절대값·변화율 RF 비교 스트레스는 실험용 API, 피로는 서버 연결 보류
03

핵심 전환점 — 점수가 아니라 실패가 다음 방향을 정했습니다

① 4분류에서 개별 이진 모델로

실제 fatigue 260개 중 92개가 normal로 분류되는 등 정상·피로 중첩이 컸습니다. 하나의 강제 분류보다 상태별 가능성을 독립적으로 보는 편이 현실적이었습니다.

② 정확도보다 그룹 분할

같은 대상자를 무작위로 섞으면 모델이 개인 고유 HRV를 외워 점수가 높아질 수 있었습니다. 이후 주요 평가는 대상자 단위 5-fold와 OOF를 기준으로 삼았습니다.

③ 공공 성능보다 실측 오탐

부정맥 모델은 공공데이터에서 높은 F1을 보였지만 실측 정상 데이터를 대부분 부정맥으로 판정했습니다. 이 결과가 개인 기준 도입의 직접적인 계기가 됐습니다.

④ 변화율이 항상 정답은 아님

급성 스트레스와 피로에서는 relative·z-score 모델이 절대값 모델보다 약간 낮았습니다. 상태의 지속시간과 라벨 특성이 모델 구조보다 더 중요하다는 결론을 얻었습니다.

프로젝트의 가장 큰 변화 — “모든 사람에게 적용되는 절대 임계값”을 만드는 것에서 “개인의 정상 상태와 비교해 이상 가능성을 보여주는 것”으로 목표가 구체화됐습니다.

05

채택한 방법과 보류한 방법

방법 기대했던 효과 확인한 결과 결정
상태별 이진 분류 정상과 각 상태의 경계를 독립적으로 학습 4분류보다 결과 해석과 데이터 구성이 명확함 채택
Random Forest 단일 모델 단순한 배포와 확률 출력 부스팅 모델과 비슷하거나 더 나은 부정맥 성능 채택
개인 정상 Calibration 개인차로 인한 정상 오탐 감소 본인 정상 평가에서 약 3~9% 확률 관찰 채택
2단 스태킹 정상/비정상 후 세부 상태 분류 앞 단계 오류 누적과 운영 복잡도 증가 우려 보류
세 모델 블렌딩 예측 분산 감소 현재 피처와 데이터에서 복잡도 대비 이득이 불명확 보류
피로 60초 API 부정맥과 같은 방식으로 즉시 분석 F1 56.64%, 정상 오탐 132/270 보류
06

정리하면

데이터를 먼저 통일

서로 다른 센서와 데이터셋을 60초 RR·HRV 피처로 변환해 비교 가능한 학습 기반을 만들었습니다.

평가는 대상자 단위로

높은 점수보다 처음 보는 사람에게 적용할 수 있는지를 중요하게 보고 그룹 5-fold와 OOF를 사용했습니다.

개인차는 Calibration으로

실측 정상 오탐을 계기로 개인의 5분 정상 profile을 실제 추론 입력에 반영했습니다.

상태별 한계를 인정

부정맥은 60초 분석을 유지하고, 스트레스와 피로는 더 긴 추세가 필요하다는 결론을 내렸습니다.

현재 결과의 위치 — Galaxy Watch와 AI 서버가 실제로 연결되는 연구용 프로토타입은 완성됐지만, 의료 진단이나 일반 사용자 성능을 주장하려면 더 많은 실측 대상자와 독립된 양성 데이터 검증이 필요합니다.
